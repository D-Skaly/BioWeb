# BioWeb - Personal Bio Page (Vietnam Market)

Landing page bio cá nhân chuyên nghiệp bằng tiếng Việt, tối ưu để deploy nhanh lên Vercel.

## Chạy local

Chỉ cần mở `index.html` trực tiếp hoặc dùng static server:

```bash
npx serve .
```

## Deploy lên Vercel

1. Push code lên GitHub.
2. Truy cập [vercel.com](https://vercel.com), chọn **Add New Project**.
3. Import repository này.
4. Vercel tự nhận diện static site và deploy.

Sau deploy, bạn có thể chỉnh nội dung trong `index.html` để cá nhân hóa.
